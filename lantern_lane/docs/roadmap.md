# Roadmap and acceptance criteria

## Initial daily loop — implemented

- [x] Walk a neighborhood, find characters and interact by keyboard/touch.
- [x] Deliver a parcel once and receive an atomic reward.
- [x] Discover and appraise a harmless anomaly.
- [x] Purchase furniture, place/rotate/store it at home and undo an edit.
- [x] Save and reload quests, money, friendship and furniture.
- [x] Export/import validated saves and keep a previous valid backup.
- [x] Optional sticker hunt and timing-based canal fishing.
- [x] Model adapter for independently produced GLBs.
- [ ] Complete a real WebGL browser playthrough and iPhone Safari touch/performance check. The available cloud browser has WebGL disabled.

## Character integration

- [ ] Integrate final Mint, Nanally and Hotori GLBs.
- [ ] Add clip crossfading, greetings and item-receive animations.
- [ ] Implement daily schedules with path-following destinations and clear interaction availability.
- [ ] Confirm characters never hide the action prompt or become unreachable.

Acceptance: the three finished models load, animate, keep their identities, and complete the same daily loop without gameplay changes.

## Neighborhood depth

- [ ] Explorable antique-shop interior and rooftop.
- [ ] Nine authored friendship story steps and 72 ambient dialogue lines.
- [ ] Repeatable job templates and a larger collectible/furniture catalog.
- [ ] A rooftop gathering that concludes the first neighborhood story.
- [ ] Shared courtyard decoration, sitting, photo mode, ambience and original music.

Acceptance: a coherent 15–20 minute slice, followed by repeatable activities; every reward and scene transition survives reload.

## Release comfort

- [ ] Measure desktop and iPhone performance and tune shadow quality/draw calls.
- [ ] Verify pointer cancellation, Safari background/resume, orientation changes and safe areas on device.
- [ ] Add save migration only when a second schema actually exists.
- [ ] Add user-selected player appearance and more accessible input options.

Optional cloud saves, more districts and multiplayer remain separate later scope.
